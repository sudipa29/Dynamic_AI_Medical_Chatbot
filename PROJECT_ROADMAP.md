# Dynamic AI Medical Information Chatbot

## Project Goal

Build a dynamic medical information chatbot using Natural Language Processing (NLP), Machine Learning, medical knowledge retrieval, Retrieval-Augmented Generation (RAG), Generative AI, contextual memory, and a safety layer.

## Main Pipeline

User Question
→ NLP Preprocessing
→ Intent Detection
→ Entity Extraction
→ Safety Classification
→ Medical Knowledge Retrieval
→ RAG
→ Generative AI
→ Response Validation
→ Final Response

## Important Safety Boundary

This project is a medical information and health-support chatbot.

It is not designed to diagnose diseases, prescribe medication, replace doctors, or provide personalized medical treatment decisions.

Potentially high-risk queries should be handled through a dedicated safety layer and appropriate professional-care guidance.
